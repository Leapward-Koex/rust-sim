How to use
==========

To run DictySim with the GUI enabled, navigate to the folder containing dicty_sim_test_env.py and run `python3 dicty_sim_test_env.py`. Alternatively, 
if you want to run without GUI from command line, incude the `--param` argument and a .json file containing all variables and values like so `python3 dicty_sim_test_env.py --param input_param.json`. An example input is provided in test_param.json

When running directly from the command line an ouput file must be specified in the input parameters as no graphs or GUI will be produced.
